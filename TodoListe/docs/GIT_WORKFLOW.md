# Git Workflow

## First Setup

```bash
cd C:\Users\lucak\Desktop\TodoListe
git init
git branch -M main
git add .
git commit -m "Initial commit: premium project command center"
git remote add origin https://github.com/YOUR_USERNAME/TodoListe.git
git push -u origin main
```

## Daily Workflow

```bash
git status
git add .
git commit -m "Describe what changed"
git push
```

## Check Remote

```bash
git remote -v
```
