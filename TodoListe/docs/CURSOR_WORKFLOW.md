# Cursor Workflow

## Model

Use Cursor Composer 2.5.

## Role

Every implementation prompt should treat the agent as a senior full-stack developer and senior product designer.

## Rules

- Keep the app premium, calm, minimal, and Apple-like.
- Preserve the folder structure.
- Keep TypeScript strict and clean.
- Avoid oversized components.
- Put business logic into utilities and hooks.
- Keep UI components reusable.
- Do not commit secrets.
- Confirm that `npm run build` works before deployment.

## Prompt Location

Use the ready-to-copy prompts in the `/prompts` folder.
