# Product Brief

## Working Name

High Value Todo

## Product Idea

A premium project command center for founders, builders, freelancers, creators, and operators who manage many projects and need a better way to identify the highest-value next action.

## Core Problem

Most todo lists treat every task as equal. In reality, some tasks create far more leverage than others.

## Core USP

The app ranks tasks by business and execution value using impact, urgency, and effort.

```txt
highValueScore = impact + urgency - effort
```

## Version 1 Scope

- Personal productivity tool
- No backend
- No login
- No payments
- localStorage persistence
- Static Hetzner deployment

## Future SaaS Scope

- Authentication
- Cloud database
- Multi-user workspaces
- Subscriptions
- Team collaboration
- AI task prioritization
- Calendar integrations
- GitHub, Notion, Linear, Slack integrations
